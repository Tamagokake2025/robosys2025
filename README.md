# alnum コマンド
- 入力されたアルファベットが、何番目かを出力する。
- 入力された1~26の数字には、対応したアルファベットを小文字で出力する。
- 大文字のアルファベットや、日本語が入力された場合には、1文字ずつUnicodeポイントを出力する。
- このUnicodeポイントを入力すると対応した文字を出力する。
- 入力した文字はそのままに、数字だけをアルファベットに変換し、つなげることも可能。
### 使用方法
　ターミナルで以下のコマンドを入力。クローン。
```
$git clone https://github.com/Tamagokake2025/robosys2025.git
```
　ディレクトリを移動。実行権限を付与。
```
$cd robosys2025
```
```
$chmod +x alnum
```
　alnumコマンドが使用可能になる。

### 実行例
1. アルファベットから数字へ
 ```
$echo "a robot" | ./alnum
1 18 15 2 15 20
 ```

2. 数字からアルファベットへ
 ```
$echo "1 18 15 2 15 20" | ./alnum
a r o b o t
 ```
  　　この実行結果を再び入力すると、数字に戻る。  

3. Unicodeポイントを出力
 ```
$echo "THANK YOU ありがとう" | ./alnum
84 72 65 78 75 89 79 85 12354 12426 12364 12392 12358
 ```

4. 文字に直す  
  コマンドラインに入力することも可能
 ```
$./alnum 84 72 65 78 75 89 79 85 12354 12426 12364 12392 12358
T H A N K Y O U あ り が と う
 ```

5. 数字でも文字でもない、記号は ？ として出力。  
  対応するアルファベットが存在しない、数字の 0 はそのまま0として出力する。
 ```
$echo " 「30日までの課題が終わらない」 " | ./alnum
? c 0 26085 12414 12391 12398 35506 38988 12364 32066 12431 12425 12394 12356 ?
 ```
  　　文字に直す
 ```
$echo " ? c 0 26085 12414 12391 12398 35506 38988 12364 32066 12431 12425 12394 12356 ? " | ./alnum
? 3 0 日 ま で の 課 題 が 終 わ ら な い ?
 ```

6. ! を最初に入力することで、入力した文字を変換しない処理が可能。その際、文字のインデントを詰めて表示する。  
! 無しの入出力
```
$echo " 73 1 13 fine  " | ./alnum
I a m 6 9 14 5
```
　　! を使った入出力
```
$echo " ! 73 1 13 fine  " | ./alnum
!Iamfine
```
### 使いどころ
- ふと「あのアルファベットは何番目かな」と思った際に調べられる。
- 文章を変換したコードを人に渡し、渡した先でコードを読み込ませることで、文章を呼び出せる。  
つまり簡易な暗号の制作、読み取りが可能。
