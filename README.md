# alnum コマンド
- 入力されたアルファベットが、何番目かを出力します。
- 入力された1~26の数字には、対応したアルファベットを小文字で出力します。
- 大文字のアルファベットや、日本語が入力された場合には、1文字ずつUnicodeポイントを出力します。
- このUnicodeポイントを入力すると対応した文字を出力します。
- 入力した文字はそのままに、数字だけをアルファベットに変換し、つなげることも可能です。
